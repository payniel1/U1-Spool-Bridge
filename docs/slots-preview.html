What the printer itself reports, read back from the same object this box writes to. It keeps showing after the spool has left the reader.

When it refreshes. Every 15 s, and immediately after a send, after a slot's occupancy changes, or on Refresh. The timer is only a backstop for changes made at the machine itself. One request. ?print_task_config&filament_detect fetches both objects, parsed through an ArduinoJson filter down to the eleven fields shown, so a four-channel blob never becomes the largest allocation on the board.
